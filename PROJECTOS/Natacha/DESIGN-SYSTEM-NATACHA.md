## 3. TIPOGRAFIA

### Fontes Oficiais

| Papel | Fonte | Característica | Uso |
|---|---|---|---|
| **Display / Títulos** | **Argesta** | Serifada elegante, traço fino, presença forte | Títulos H1, nome da marca, capas |
| **Corpo / Apoio** | **Bellefair** | Serifada geométrica, traço consistente, leitura fácil | Corpo de texto, subtítulos, legendas |

> **Nota:** Argesta não está disponível no sistema padrão — em documentos Word/Google Docs, usar **Cormorant Garamond** ou **IM Fell English** como substituto de emergência. Para produção gráfica (Canva, Illustrator), usar Argesta original.

### Hierarquia Tipográfica (documentos)

| Nível | Fonte | Tamanho | Cor | Estilo |
|---|---|---|---|---|
| H1 — Título principal | Argesta | 36–48pt | Vermelho `#A9101C` | Normal (não bold) |
| H2 — Subtítulo secção | Bellefair | 22–26pt | Dourado `#B7821A` | Bold |
| H3 — Sub-secção | Bellefair | 18–20pt | Vermelho `#A9101C` | Bold |
| Corpo | Bellefair | 11–12pt | Preto suave `#1A1A1A` | Normal |
| Citação / Destaque | Bellefair | 11pt | Cinza `#6B6B6B` | Itálico |
| Label / Tagline | Bellefair | 9–10pt | Qualquer | Caixa alta, espaçado |
| Cabeçalho / Rodapé | Bellefair | 9pt | Cinza `#6B6B6B` | Normal |

### Regras Tipográficas

- **Espaçamento de letras:** Labels e taglines sempre com `letter-spacing` amplo (0.15–0.25em)
- **"TREINAMENTOS"** aparece sempre em caixa alta, espaçado, tamanho 50–60% do nome principal
- **Nunca bold** em Argesta — a elegância vem da leveza
- **Nunca sans-serif** em materiais da marca — a identidade é 100% serifada

## 5. ELEMENTOS GRÁFICOS

### Separadores

- Linha fina (`1–2px`) na cor **Dourado** `#B7821A` — uso principal
- Linha fina na cor **Vermelho** `#A9101C` — cabeçalhos e rodapés
- Nunca usar linhas cinzas genéricas

### Caixas de Destaque / Citações

- Borda esquerda `4–6px` Dourado + fundo bege claro `#F5EFE6`
- Texto em itálico, Bellefair, cinza elegante `#6B6B6B`

### Tabelas

- Cabeçalho: fundo **Vermelho** `#A9101C`, texto branco, Bellefair bold
- Linhas alternadas: branco `#FFFFFF` / bege claro `#F5EFE6`
- Borda entre células: linha fina Bege `#CDB89F`
- Sem bordas externas grossas — elegância minimalista

### Bullets / Listas

- Marcador: `›` ou `·` na cor Dourado `#B7821A`
- Nunca bullet genérico preto
- Indentação de 0.5cm

### Blocos de Texto com Destaque

```
╔══════════════════════════════╗   ← borda Dourado fino
║  Texto de destaque           ║   ← Fundo bege claro
╚══════════════════════════════╝
```


### Rodapé Padrão

```
──────────────────────────────────────────────────────────── (linha bege)
[Centro] Natacha António Treinamentos · Página X de Y
```

### Capa Padrão (estrutura)

1. **Bloco superior** — fundo Vermelho, logo branco centrado (símbolo + wordmark)
2. **Linha dourada** separadora
3. **Título do documento** — Argesta, grande, Vermelho, centrado
4. **Subtítulo** — Bellefair, itálico, cinza
5. **Dados** (para, data, versão) — Bellefair, pequeno, centrado
6. **Bloco inferior** — linha bege + "Elaborado por [nome]"

## 9. REGRAS DE PRODUÇÃO — CHECKLIST OBRIGATÓRIO

Antes de entregar qualquer documento da Natacha, verificar:

- [ ] Cores correspondem **exactamente** à paleta (sem aproximações genéricas)
- [ ] Fontes: Argesta (títulos) + Bellefair (corpo) — ou substitutos aprovados
- [ ] Logo na variante correcta para o fundo usado
- [ ] Cabeçalho e rodapé presentes em todas as páginas (excepto capa)
- [ ] Separadores em Dourado (não cinza genérico)
- [ ] Tabelas com cabeçalho Vermelho e linhas alternadas Bege
- [ ] Bullets com marcador `›` Dourado
- [ ] Tom de voz feminino, directo, inspirador
- [ ] Nenhum elemento azul, verde ou cor fora da paleta
